# Internship Fit 中文使用说明

这是一个可定制的本科生实习申请工作台。第一版重点是“核对资格有依据，简历内容来自真实经历”。它可以独立运行，也可以由学生社团修改后使用。

## 你现在能做什么

1. **我的经历**：填写学校、专业、毕业年份和技能；添加课程项目、研究、社团、工作经历。这里不按性别或学校声望进行推荐。
2. **岗位工作台**：粘贴招聘说明；提取技能关键词；自己确认哪些是硬条件、哪些只是加分项，并保留原文依据。
3. **定制工具**：改变名称、颜色、兴趣关键词、地点偏好、排序权重、筛选条件、简历模板和栏目顺序。
4. **一页简历**：选择目标岗位及真实经历；查看排版；使用浏览器打印为 PDF。长内容会超过一页，需要删减或换紧凑模板，不会偷偷删掉文字。
5. **申请记录**：收藏岗位，保存当时的简历版本，手动记录投递和面试进度。

示例档案与四个示例岗位都是虚构的。它们帮助你试用工具，不能作为自己的真实申请材料。

## 如何在电脑上运行

需要 Node.js 22.9 以上，建议使用 Node 24。解压项目或下载仓库后，在项目文件夹打开终端：

```sh
npm start
```

再打开 `http://localhost:3000`。不需要先安装项目依赖，也不需要付费 AI 密钥。直接双击网页文件不能可靠运行。

## 个性化修改

- 只想看带薪远程机会：在设置里勾选条件。
- 愿意继续核对未说明报酬的岗位：保留“未知”，不要勾选严格隐藏未知条件。
- 更看重研究方向：提高兴趣权重，加入研究方向关键词。
- 给社团使用：修改名称、主题色、岗位公司列表，导出配置发给成员。
- 想让经历放在教育前：修改简历栏目顺序。
- 想改模型或程序逻辑：阅读 `docs/customization.md`。

**配置导出不包含个人资料。完整备份包含个人资料和简历，不能放进公开 GitHub 仓库。**

## 真实岗位来源

在设置中添加 Greenhouse 或 Lever 的公司招聘板标识，再点击“同步”。标识是招聘网址中的公司段，不是整条链接。第一版只读取你添加的公司、且标题包含实习关键词的职位。本科资格、工作时间、工作授权等仍需要核对。

在线静态体验版可能受招聘网站跨域限制，导致同步失败。遇到这种情况可以粘贴招聘说明，或使用本地 Node 服务器的接口。同步成功不代表已经验证所有字段，也不代表岗位一直在招。

## 可选 AI

核心功能不依赖 AI。需要改写建议时，在本地 `.env` 配置自己的兼容模型服务；复制 `.env.example` 并填写服务地址、模型名称和密钥。

密钥只放服务器，不要发到聊天或公开仓库。模型调用可能收费，由所选服务提供商决定。

界面会先说明发送哪些文字，再让你确认。生成内容逐条展示原始事实，你核对后才能接受。检测新增数字只是基础保护，不代表能自动证明所有改写真实。

## 如何理解判断

- **已确认**：用户核对的岗位字段和个人档案一致，或记录了明确的信息。
- **待确认**：没有足够信息；绝不自动当成符合。
- **冲突**：存在已确认的本科资格、毕业年份冲突，或岗位已关闭。
- **待补充**：个人档案尚未列出某项必需技能，需要核实，不能推定你一定不会。
- **偏好排序分数**：已知技能、兴趣、地点的简单加权分数，不是录取概率。

## 开源发布

将源码文件提交到自己的项目仓库即可。许可证为 MIT。保留 README、许可证、测试与示例。不要上传 `.env`、真实简历、私人备份或运行中保存的数据。网页版可以部署静态 `dist` 目录；需要服务器 AI 功能时另行配置安全的后端。

当前版本没有自动投递、全网岗位收集或跨设备同步。完整功能范围与验证限制见英文 README 和 `docs/validation.md`。

### 中英文界面

首次打开默认使用英文，可在右上角切换为简体中文。浏览器会记住语言选择，切换时保留当前页面和未保存的表单内容。中文界面按日常使用习惯重新撰写；岗位原文、个人经历和自定义内容保持原样。简历栏目目前仍采用适合美国实习申请的英文格式。
