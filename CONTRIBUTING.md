# Contributing

Use fictional cases when reporting issues. Explain expected and actual behavior, your browser/runtime version, and reproduction steps. Never attach real resumes, private backups, credentials or identifiable applicant records.

For code changes:

1. Create a focused branch.
2. Keep UI changes accessible and readable on small screens.
3. Add a regression case when changing qualification, matching, import or provider logic.
4. Run `npm test` and `npm run build`.
5. Describe the user-visible behavior and remaining limitations in your pull request.

Useful contributions: new permitted source adapters, better multilingual skill normalization, accessible resume templates, and evidence-backed qualification test cases. Do not introduce demographic ranking, invented application claims, opaque hiring-probability scores, or automatic submission without explicit user control.
